====================================================================================
Purchase Return at Original Cost
====================================================================================

This module allows reversing a validated purchase receipt using the original
stock valuation cost at which the products were received.

Installation
====================================================================================

Install the module normally from the Apps menu.

Usage
====================================================================================

1. Go to a validated purchase receipt (Inventory > Operations > Receipts).
2. Click the "Revertir Recepcion" button.
3. Specify the quantities to return and the destination location.
4. Validate the return.

The stock valuation will be created using the original unit cost from the
receipt, not the current average cost.
