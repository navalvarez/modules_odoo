Purchase Return at Original Cost

Reverse a validated purchase receipt using the original stock valuation cost at which the products were received, instead of the current Average Cost (AVCO).

Why use this module?

In Odoo, when you return a purchase receipt, the stock valuation is created using the current average cost at the time of the return. This can cause discrepancies in inventory valuation and accounting entries, especially when prices have changed since the original receipt.

This module solves that problem by using the historical unit cost from the original receipt, ensuring accurate inventory valuation.

Key Features

  • Adds a "Revertir a costo original" button to validated purchase receipts.
  • Uses the original valuation cost (from the Stock Valuation Layer of the receipt) instead of the current AVCO.
  • Reuses the native Odoo return wizard for a familiar user experience.
  • Works seamlessly with Odoo's standard inventory and accounting flows.

How to Use

  1. Go to a validated purchase receipt (Inventory > Operations > Receipts).
  2. Click the "Revertir Recepción" button.
  3. In the wizard, specify the quantities to return and the destination location.
  4. Click "Revertir" to create and validate the return.

Note: The wizard will show additional columns (Received, Already Reverted, Available, Original Cost, Original Value) to help you decide the quantities to return.
